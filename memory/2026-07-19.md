# Bounded Hermes Mine Staging Implementation

Implemented a focused integration from clean `main` instead of merging the
large `cursor/brain-next-steps-plan` branch. The deterministic catalogue remains
the durable retrieval foundation.

The Hermes Miner reads only the configured Hermes memory root, refuses
symlinked sources and archive paths, conservatively rejects credential-bearing
blocks, emits no more than 20 candidates, writes only the ignored mine staging
file, and fingerprints durable domains plus `catalog.md` before and after a
pass. Promotion remains a separate Gate responsibility.

0 errors, and all 10 deterministic retrieval benchmark questions returned the
expected evidence with the established 67% token reduction.
