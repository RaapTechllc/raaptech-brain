# References Memories

## Brain retrieval CLI (2026-07-07)

The brain bundle has a deterministic retrieval CLI at scripts/brain.py — use 'python scripts/brain.py ask' before opening files, 'brain save' to store durable facts, 'brain reindex' to rebuild catalog.md, and 'brain bench' as the regression suite.
