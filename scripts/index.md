# Scripts

* [brain.py](/scripts/brain.py) — Deterministic retrieval CLI: `ask`, `save`, `reindex`, `bench`, `html` (stdlib-only)
* [okf-validate.py](/scripts/okf-validate.py) — Validate OKF bundle conformance (frontmatter, structure)
* [sync-google-drive.py](/scripts/sync-google-drive.py) — Push/pull knowledge documents between the brain and Google Drive
* [vault-bridge.py](/scripts/vault-bridge.py) — Bridge to the RaapTech-Vault Obsidian workspace (status, search, verify)
* [bench-questions.json](/scripts/bench-questions.json) — Benchmark question set for `brain.py bench`
